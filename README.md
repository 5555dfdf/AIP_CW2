## 4. 已确认的数据清洗规则

### 4.1 最终决定

> **只要图像属于完全重复组，无论是否跨集合、标签是否一致，都整组排除。该组任何图片记录均不进入实验清单。**

该规则同时适用于同集合内重复、跨集合重复和标签冲突的完全重复图像。即使重复图像只存在于训练集，也不保留其中任何一张。

此前讨论过的“重复组保留一张”或“按 train > val > test 优先保留”方案已被本规则替代，不再采用；此前的 4,148 张清理后样本估计也不再适用。

### 4.2 判重范围与方法

在九种植物组成的完整作业子集中，合并检查 train、val、test，使用两种一致性证据：

1. **文件 SHA-256**：对原始文件字节计算摘要，识别字节完全相同的文件。
2. **RGB 像素 SHA-256**：使用 Pillow 解码图片、转换为 RGB，对明确编码的图像宽高及完整 RGB 像素字节计算摘要，识别编码或元数据不同但解码像素完全一致的图片。

文件摘要相同或 RGB 像素摘要相同的记录归入同一重复组；分组必须合并两种关系形成的连通组，不能分别处理后遗漏关联记录。组内记录数大于 1 时，全部排除。

实施时还应固定并记录尺寸编码方式、像素字节顺序和解码库版本，使哈希可以复现。判重使用原始解码尺寸，不在判重前缩放、裁剪、增强或进行模型输入变换；不能用平均颜色、颜色直方图等代替完整像素一致性判断。

### 4.3 文件与划分处理

- **保留原始图片和标注文件，不物理删除、不移动。** 通过清单中的状态和原因排除样本。
- 不重新随机划分，也不把图片从一个集合转移到另一个集合；保留记录沿用其原始集合。
- 训练前固定清洗规则和最终清单，所有基线、改进模型及最终评估使用相同的清单。
- 允许读取所有集合的文件和标签开展数据完整性、重复及冲突审计；不得根据测试预测结果或测试性能调整清洗规则。
- 近重复图像，例如缩放、裁剪、加水印或重新压缩后像素发生变化的版本，不属于本次“完全重复”自动排除规则。后续应检查并单独记录，未解决的近重复泄漏须在报告中作为局限性说明。

### 4.5 清单与审计输出约定

建议保留包含全部候选记录的审计清单，再由 `included=True` 生成供实验使用的清单。字段至少包括：

## 6. 训练、选择与评估原则

- 训练集用于学习参数、计算类别权重和估计数据集专属预处理统计；也可以使用预训练权重文档规定的归一化参数。
- 验证集用于选择配置、训练轮次及最佳 checkpoint，主要依据为 **Macro-F1**。
- 在最终测试前固定所有计划中的模型、受控比较及评估方式；测试集用于冻结后的最终评估和错误分析，不用于反复调参。
- 评估使用 `model.eval()`，禁用梯度；冻结骨干时应明确其 BatchNorm 等层的运行模式。
- 固定并记录随机种子、依赖版本、硬件、训练时间、预训练权重标识、超参数和 checkpoint 选择规则。
- 允许 ImageNet 等通用预训练权重；不得使用已在 PlantSeg 或重叠 PlantWild 图像上训练过的权重。
- 必须报告测试集 Macro-F1、Top-1 accuracy、balanced accuracy、每类 precision/recall/F1/support，以及完整混淆矩阵。
- Macro-F1 是各类别 F1 的平均值，不是先平均 precision 和 recall 再计算 F1。固定类别顺序，明确零除和无评估样本类别的处理方式。
- 保留训练/验证曲线、类别分布图和含正确及错误案例的预测图。报告中的所有数据图和结果表都须由 Notebook 重新生成。
